```{admonition} Try out the new Reqnroll IDE Support (preview)
:class: important

The Reqnroll team now provides [**Reqnroll IDE Support**](../ide-support/index) for all three major
IDEs used by Reqnroll developers — **Visual Studio**, **Visual Studio
Code**, and **JetBrains Rider** — with the same advanced feature set across
all of them: syntax highlighting, diagnostics, completion, navigation
between steps and bindings, refactoring, and more. Whichever IDE you use,
you get the same capabilities and the same editing experience.

**This is an early preview, and your experience will help us shape the future of Reqnroll IDE support.** Please try it in your day-to-day work and let us know what works well, what is missing, or where you run into problems. Share feedback or report issues in the [Reqnroll.IdeSupport GitHub repository](https://github.com/reqnroll/Reqnroll.IdeSupport/issues).
```
